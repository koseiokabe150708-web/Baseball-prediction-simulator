# Baseball-prediction-simulator

A baseball prediction simulator in Python that predicts the future performance of baseball players from the Tokyo Yakult Swallows in NPB based on historical statistics.


## Features
- Select a batter from the Tokyo Yakult Swallows team.
- Choose how many years of historical data to be used for prediction.
- The predicted stats such as batting average and home runs are displayed.
- The number of games in which the player will contribute to team's victories will be displayed.
- Statistics by opposing team will be displayed.

## Tools
- Python
- SQLite3
- Tkinter
- Google Sheets
